# 🚗 Smart Parking Management System

A simple and user-friendly **Smart Parking Management System** designed to help users find parking locations, check parking availability, book parking slots, and view their booking history.

## 📌 Project Overview

The Smart Parking Management System provides an easy way to manage parking digitally. Users can explore available parking locations, filter parking areas based on type, find nearby parking, book available slots, and view their previous bookings.

The project is designed as a web-based application with a simple and responsive interface.

## ✨ Features

* 🏠 **Home Page** – Easy navigation to different sections.
* 📍 **Parking Locations** – View available parking locations.
* 🔎 **Search Parking** – Search for specific parking locations.
* 🅿️ **Parking Filters** – Filter between free and paid parking.
* 📡 **Find Nearby Parking** – Find parking locations near the user.
* 🎫 **Slot Booking** – Book an available parking slot.
* 💰 **Automatic Fee Calculation** – Calculate parking charges based on the location.
* 📋 **My Bookings** – View booking history and booking details.
* 🧾 **Booking Receipt** – Display booking and payment details.
* 👨‍💼 **Admin Section** – Manage parking-related information.
* 📱 **Responsive Design** – Simple interface suitable for different screen sizes.

## 🚀 How to Run the Project

### 1. Clone the Repository

```bash
git clone <your-github-repository-url>
```

### 2. Open the Project

Open the project folder in **Visual Studio Code**.

### 3. Run the Website

You can use the **Live Server** extension in VS Code.

Right-click on `index.html` and select:

```text
Open with Live Server
```

The website will open in your browser.
